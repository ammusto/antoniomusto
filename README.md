# antoniomusto.com

Personal site. Plain HTML and CSS, no build step.

- `index.html` – home
- `cv.html` – CV (embeds `CV.pdf`)
- `publications.html` – projects and publications
- `dh-projects.html` – digital humanities projects
- `style.css` – shared styles

To update the CV, replace `CV.pdf`. To preview locally, open `index.html` in a browser or run any static file server from this folder.
